Bilder
Lägg NP-bilder här som PNG eller JPG.
Namnge bilderna så att de matchar `image`-fältet i `questions/manniskokroppen.json`.
Exempel:
`reproduktion\_underliv.png` — används av fråga mk_03
`nervsystem\_reflexbage.png` — kan användas av mk_15
Tips: Exportera bilder från PDF-proven och spara dem här.
Bilderna visas automatiskt bredvid frågan i appen om filnamnet matchar.
